# 도파민 게임 규칙표 (규칙 버전 1.1.0)

수치의 단일 출처는 `src/shared/rules/actionData.ts`이다(행동별 수치 `ACTION_DATA`, 유형 공통 규칙 수치 `RULE_DATA`). 카드 설명(`ACTIONS[].description`)은 이 데이터에서 자동 생성되므로 항상 아래 표와 같다. 이 문서의 수치는 6단계 봇 시뮬레이션으로 조정한 값이다(조정 근거와 이전 값은 `docs/BALANCE.md`). 수치를 바꾸면 이 문서와 `npm run sim` 결과를 함께 갱신한다.

## 1. 기본값

| 항목 | 값 |
|---|---|
| 목표 점수 | 100 |
| 최대 일수 | 10일 (10일째 밤 종료 후 최고 점수 승리) |
| 낮 행동력 | 3 (슬롯 3칸, 순서 있음) |
| 밤 자동 행동 | 2회 (습관 가중 복원 추출) |
| 낮 제한시간 / 밤 결과 표시 | 45초 / 8초 |
| 인원 | 2~6명 |
| 초기 상태 | 점수 0, 모든 사용 횟수·습관 0 |

## 2. 용어

- **회차**: 이번 사용이 몇 회째인지 = (기존 누적 사용 횟수) + 1. 보상 단계는 회차로 정한다. 사용 후 누적 사용 횟수 +1.
- **누적 사용 횟수(uses)**: 게임 전체 누적. 회복으로 줄지 않는다. 회복 행동 자신도 사용 횟수는 증가한다(단계가 없어 영향 없음).
- **습관(habits)**: 밤 추첨 확률에만 쓴다. 일반 행동(즉시·안정·성장)을 **낮에** 실행하면 +1. 밤 실행·회복 행동은 습관을 만들지 않는다. 0 미만 불가.
- **하루 사용 횟수(dailyUses)**: 낮+밤 합산, 다음 낮 시작 시 0.
- **연속 사용(streak)**: 같은 날 직전 *실제 행동*이 같은 행동이면 연속. 낮 슬롯 3 → 밤 1회차로 이어진다. 무행동(소비된 칸 포함)·회복 행동이 끊고, 다음 낮 시작 시 초기화.
- **낮 전용 부가효과**: 산책·회복의 습관 감소, 친구 보너스, 봉사 보너스. 밤에는 발생하지 않는다. 음악의 밤 보너스는 밤 전용이다.
- 쇼핑 재사용 감점, 게임 몰아하기 연속 감점, 요리 첫 사용 보너스, 공부 하루 1회 고단계 제한, **초반 도파민 보너스**, **같은 날 반복 피로**는 **보상 조건**이므로 낮·밤 모두 적용한다(하루 기준은 낮+밤 합산).
- **일차**: 1일째부터 센다. 초반 도파민 보너스는 정산 중인 일차로 정한다(그날 밤 추첨도 같은 일차).

## 3. 행동 규칙표

### 유형 공통 규칙 (규칙 버전 1.1.0에서 추가)

| 규칙 | 대상 | 정의 |
|---|---|---|
| **초반 도파민 보너스** | 즉시 행동 6개 | 1일째 **+3**, 2일째 **+2**, 3일째부터 0. 그 행동의 결과(회차 보상 + 쇼핑 재사용·게임 연속 감점까지 합친 값)가 **양수일 때만** 더한다. 도박은 승리일 때만(패배는 음수라 없음). 낮·밤 모두. 기록: `초반 보너스 +3` |
| **같은 날 반복 피로** | 안정 5개 + 성장 5개 | 같은 행동을 같은 날(낮+밤 합산) **5회째** 이상 쓰면 그 사용의 결과를 회차 보상·단계 도달·완료·밤·첫 사용·공동 보너스와 관계없이 **+1**로 대체한다. 낮·밤 모두. 회차(누적 사용)와 하루 사용 횟수는 그대로 증가한다. 기록: `같은 날 5회째 피로: +1` |

- 같은 날 5회째는 낮 3칸을 모두 같은 행동으로 채우고 밤 2회도 그 행동이 뽑힐 때 생긴다. 한 행동만 쌓으면 밤 추첨도 그 행동으로 몰려 하루 5회가 되는 문제를 막는다.
- 피로는 공부의 하루 1회 고단계 제한보다 우선한다. 피로로 대체된 사용은 고단계 보상을 받지 않으므로 하루 1회 기록도 남기지 않는다.
- 도박·창작은 피로여도 난수를 1개 쓴다(난수 순서 유지).
- 처리 순서: 행동별 보상·조건 합산 → (안정·성장) 피로면 +1로 대체 → (즉시) 합계가 양수면 초반 보너스 추가 → 점수 하한 보정.
- 회복 행동에는 두 규칙 모두 없다.

### 즉시 (습관 형성)

| 행동 | 회차별 점수 | 추가 조건 |
|---|---|---|
| 음주 | 1회 **+7** / 2회 **+3** / 3~4회 **-4** / 5회~ **-8** | — |
| 흡연 | 1~2회 **+3** / 3~4회 **0** / 5회~ **-3** | — |
| 도박 | 1~2회 승률 50% **+9** / 패 **-3** (기대 +3)<br>3~4회 승률 35% **+8** / 패 **-5** (기대 -0.45)<br>5회~ 승률 20% **+7** / 패 **-8** (기대 -5) | 승패 난수는 밤 추첨과 별도로 한 번 더 뽑는다 |
| SNS | 1회 **+4** / 2회 **+1** / 3~4회 **-1** / 5회~ **-4** | — |
| 쇼핑 | 1회 **+7** / 2회 **+2** / 3회 **-3** / 4회~ **-6** | 같은 날(낮+밤) 이미 쇼핑했으면 추가 **-3** |
| 게임 몰아하기 | 1회 **+7** / 2회 **+2** / 3회 **-3** / 4회~ **-6** | 직전 실제 행동도 게임 몰아하기(연속)면 추가 **-3** |

- 위 점수는 3일째부터의 값이다. 1~2일째에는 결과가 양수면 초반 도파민 보너스(+3/+2)가 붙는다.

### 안정 (습관 형성)

| 행동 | 점수 | 추가 조건 |
|---|---|---|
| 산책 | **+2** | 낮: 지정 대상 습관 **-1** (자기 습관 +1을 먼저 적용하므로 산책 자신을 대상으로 하면 순변화 0) |
| 음악 감상 | **+2** | 밤 추첨으로 실행되면 추가 **+3** (밤 합계 +5) |
| 요리 | **+2** | 그날(낮+밤) 첫 요리면 추가 **+3** (첫 요리 합계 +5) |
| 친구 만나기 | **+3** | 낮: 같은 슬롯 번호에서 비기권자 2명 이상이 친구 만나기를 고르면 각자 추가 **+3** |
| 봉사 활동 | **+2** | 낮: 그 슬롯 처리 직전 비기권자 전체 중 최저 점수(동점 포함)면 추가 **+5** |

### 성장 (습관 형성)

| 행동 | 점수 | 추가 조건 |
|---|---|---|
| 공부 | 1~2회 **+1** / 3~4회 **+3** / 5~7회 **+5** / 8회~ **+9** | +5·+9(고단계) 보상은 하루(낮+밤) **1회**. 같은 날 그 이후 고단계 회차는 기본 **+2** (회차는 계속 증가) |
| 운동 | 1~3회 **+1** / 4~7회 **+2** / 8~12회 **+3** / 13회~ **+4** | 공부 같은 하루 1회 제한은 없음 (같은 날 5회째부터 피로는 적용) |
| 업무·프로젝트 | 매회 **+2** | 회차가 3의 배수(3, 6, 9…)면 완료 보너스 **+7** |
| 창작 활동 | 매회 **+1** | 완성 보너스 **+10**, 확률 = 회차 × 4% (최대 30%, 8회째부터 30%) |
| 관계·연애 | 1단계(1~2회) **+1** / 2단계(3~6회) **+2** / 3단계(7~12회) **+3** / 4단계(13회~) **+4** | 단계에 처음 들어서는 회차에 도달 보너스: 3회째 **+2**, 7회째 **+3**, 13회째 **+4**. 개인 진행, 다른 사람 입력 불필요 |

### 회복 (습관 형성 안 함 → 밤에 뽑히지 않음)

| 행동 | 행동력 | 점수 | 효과 (낮에만) |
|---|---|---|---|
| 휴식 | 1 | 0 | 지정 대상 습관 **-3** |
| 명상 | 1 | **+1** | 지정 대상 습관 **-1** |
| 디지털 디톡스 | 1 | 0 | SNS·게임 몰아하기 습관 각 **-2** (대상 지정 없음) |
| 환경 바꾸기 | **2** | 0 | 지정 대상 습관을 **0**으로 |

- 안정·성장 행동은 모두 같은 날 5회째부터 피로(+1). 위 표의 점수는 피로가 아닐 때의 값이다.
- 대상은 일반 행동(즉시·안정·성장 15개) 중 하나. 자기 습관을 대상으로 해도 된다. 산책·휴식·명상·환경 바꾸기는 대상 필수, 그 외는 대상 지정 불가.
- 환경 바꾸기는 `slots[i]`(i = 0 또는 1)에 두고 `slots[i+1]`은 반드시 빈 칸(null). 효과는 i번째 슬롯 처리 때 적용, i+1번째는 "진행 중"(무행동 취급, 연속 끊김).

## 4. 정산 순서

**낮 시작:** 비기권자의 하루 사용 횟수·연속 사용·하루 단위 기록(공부 고단계 사용 여부) 초기화. 미제출·잘못된 계획은 무행동 3칸.

**낮 슬롯:** 슬롯 0 → 1 → 2. 각 슬롯마다
1. 처리 직전 상태로 공동 효과 판정: 최저 점수(동점 포함) 참가자 목록, 친구 만나기 선택 인원.
2. 모든 참가자의 해당 슬롯을 처리(서로의 상태에 영향 없음 → 처리 순서와 무관).

**행동 1개 처리:** ① 회차 보상·조건부 보너스/감점 합산 ①-1 (안정·성장) 같은 날 5회째 이상이면 결과를 +1로 대체 ①-2 (즉시) 합계가 양수면 그 일차의 초반 보너스 추가 ② 점수에 더하고 0 미만이면 0 ③ 누적·하루 사용 횟수 +1 ④ 연속 사용 갱신 ⑤ (낮만) 일반 행동이면 자기 습관 +1 ⑥ (낮만) 대상 습관 감소(0 하한).

**밤:** 낮 효과를 모두 적용한 습관으로 분포 확정. 행동 A 확률 = A 습관 / 습관 합계. 2회 복원 추출(합계 0이면 2회 모두 무행동). 뽑힌 행동은 회차 보상·확률·음악 밤 보너스·보상 조건(초반 보너스·반복 피로 포함)만 적용하고 사용 횟수를 올린다. 습관은 바뀌지 않는다.

**난수 순서(재현용):** 참가자는 playerId 문자열 오름차순으로 처리한다(입력 배열 순서와 무관). 낮에는 슬롯 순서대로 도박·창작이 난수를 1개씩 쓰고, 밤에는 참가자별로 [추첨, (도박·창작이면) 내부 난수, 추첨, (내부 난수)] 순서로 쓴다. 추첨은 `rng × 습관합계`를 행동 목록 순서(음주, 흡연, 도박, SNS, 쇼핑, 게임, 산책, 음악, 요리, 친구, 봉사, 공부, 운동, 프로젝트, 창작, 관계)로 누적해 고른다.

**승리 판정(밤 이후):** 비기권자 0명 → 승자 없이 종료 / 1명 → 그 사람 승리 / 최고 점수 ≥ 100 → 최고 점수자 전원(공동) 승리 / 그 외 10일째면 최고 점수자 전원 승리 / 아니면 다음 낮.

## 5. 예시 한 턴 (2인, 3일째)

**시작 상태 (2일째 밤 종료 후)**

| | 점수 | 누적 사용 | 습관 |
|---|---|---|---|
| A | 30 | 음주 3, 음악 2, 공부 4 | 음주 3, 음악 2, 공부 2 |
| B | 24 | 쇼핑 2, 친구 1 | 쇼핑 2, 친구 1 |

**계획** — A: [공부, 친구 만나기, 휴식→음주] / B: [봉사 활동, 친구 만나기, 쇼핑]

3일째이므로 초반 도파민 보너스는 없고, 어느 행동도 하루 5회에 닿지 않아 피로도 없다.

**낮 슬롯 0** (직전 점수 A 30, B 24 → 최저 B)
- A 공부: 5회째 = 고단계 +5 (오늘 첫 고단계) → **35**, 공부 습관 3
- B 봉사: 기본 +2, 최저 점수 보너스 +5 = +7 → **31**, 봉사 습관 1

**낮 슬롯 1** (친구 만나기 선택 2명)
- A 친구: +3 + 친구 보너스 +3 → **41**, 친구 습관 1
- B 친구: +3 + 3 → **37**, 친구 습관 2

**낮 슬롯 2**
- A 휴식(대상 음주): 점수 0 → **41**, 음주 습관 3 → 0 (공부·휴식의 누적 사용은 유지, 휴식 사용 1)
- B 쇼핑: 3회째 -3 (오늘 첫 쇼핑이라 재사용 감점 없음) → **34**, 쇼핑 습관 3

**밤 분포**
- A: 음악 2, 친구 1, 공부 3 (합 6) → 음악 33%, 친구 17%, 공부 50%. 누적 구간: 음악 [0,2), 친구 [2,3), 공부 [3,6)
- B: 쇼핑 3, 친구 2, 봉사 1 (합 6) → 쇼핑 50%, 친구 33%, 봉사 17%. 누적 구간: 쇼핑 [0,3), 친구 [3,5), 봉사 [5,6)

**밤 추첨** (난수 0.6, 0.2, 0.1, 0.7 순서. A가 먼저)
- A 1회: 0.6×6 = 3.6 → 공부, 6회째는 고단계지만 오늘 이미 받음 → 기본 +2 → **43**
- A 2회: 0.2×6 = 1.2 → 음악, 기본 +2 + 밤 보너스 +3 = +5 → **48**
- B 1회: 0.1×6 = 0.6 → 쇼핑, 4회째 -6, 같은 날 재사용 -3 = -9 → **25**
- B 2회: 0.7×6 = 4.2 → 친구, 기본 +3 (밤에는 친구 보너스 없음) → **28**

**결과:** A 48, B 28. 둘 다 100 미만이고 3일째 < 10 → 4일째 낮으로. 밤에 습관은 변하지 않았다(A: 음주 0·음악 2·친구 1·공부 3). B는 쇼핑 습관을 정리하지 않아 밤에 큰 손실을 봤다. 이 예시는 실제 `resolveDay`로 같은 결과가 나오는 것을 테스트(`rules.test.ts`의 "docs/RULES.md 예시 한 턴")로 확인한다.

### 예시 2 (2인, 1일째): 초반 도파민 보너스와 같은 날 반복 피로

시작 상태는 둘 다 점수 0, 사용 횟수·습관 없음. 계획 — C: [음주, 쇼핑, 공부] / D: [운동, 운동, 운동]. 밤 난수 0.1, 0.5(C), 0.3, 0.9(D) 순서.

- C 낮: 음주 1회째 +7 + 초반 보너스 +3 = **+10**, 쇼핑 1회째 +7 + 3 = **+10**, 공부 1회째 +1(성장이라 보너스 없음) → **21**. 습관 음주 1·쇼핑 1·공부 1.
- C 밤 1회: 0.1×3 = 0.3 → 음주 2회째 +3, 양수이므로 초반 보너스 +3 = **+6** → **27**.
- C 밤 2회: 0.5×3 = 1.5 → 쇼핑 2회째 +2, 같은 날 재사용 -3 → 합계 -1(양수가 아니므로 보너스 없음) → **26**.
- D 낮: 운동 1~3회째 각 +1 → **3**. 습관 운동 3뿐이라 밤 2회 모두 운동.
- D 밤 1회: 운동 4회째(그날 4회째) +2 → **5**.
- D 밤 2회: 운동 5회째, 그날 **5회째 → 피로 +1** (원래 +2) → **6**.

이 예시도 `rules.test.ts`의 "예시 2: 1일째 초반 보너스와 같은 날 반복 피로"에서 실제 `resolveDay`로 확인한다.

## 6. 밸런스 근거

`npm run sim` (전략 10종: 기존 6종 + 한 행동 반복 4종, 2·4·6인 각 1,000시드 + 2인 1:1 대전표, 결과 `sim/results/summary.json`) 기준 요약. 자세한 방법·표·한계는 `docs/BALANCE.md`(7장이 규칙 1.1.0 변경).

- 평균 종료 일차: 2인 6.29일 / 4인 5.87일 / 6인 5.70일.
- 즉시 보상만 돌려 쓰면 10일 동안 100점에 도달하지 못하고(도달률 0%), 손실 전에 이긴 경우 0%.
- 초반 도파민 보너스로 "초반 즉시 후 성장 전환"이 1:1에서 안정형 52%, 성장형 60%로 경쟁력이 생겼다(규칙 변경 전 20% / 19%).
- 같은 날 반복 피로로 한 행동만 3칸 반복하는 전략은 안정·성장·혼합형 상대 최대 5%로 떨어졌다(변경 전 관계·연애 반복이 안정형 상대 93%).
- 남은 과제: 계산형 봇(혼합형·탐욕형)이 여전히 고정 계획 봇(안정형·성장형)보다 강하고, 4인에서는 혼합형 승률이 가장 높다. 실제 그룹 플레이로 확인이 필요하다.
