# 도파민 게임 규칙표 (규칙 버전 1.0.0)

수치의 단일 출처는 `src/shared/rules/actionData.ts`이다. 카드 설명(`ACTIONS[].description`)은 이 데이터에서 자동 생성되므로 항상 아래 표와 같다. 이 문서의 수치는 1단계 초기값이며, 6단계 시뮬레이션 결과에 따라 조정한다(조정 시 이 문서도 함께 갱신).

## 1. 기본값

| 항목 | 값 |
|---|---|
| 목표 점수 | 100 |
| 최대 일수 | 10일 (10일째 밤 종료 후 최고 점수 승리) |
| 낮 행동력 | 3 (슬롯 3칸, 순서 있음) |
| 밤 자동 행동 | 2회 (습관 가중 복원 추출) |
| 낮 제한시간 / 밤 결과 표시 | 45초 / 8초 |
| 인원 | 2~6명 |
| 초기 상태 | 점수 0, 모든 사용 횟수·습관 0 |

## 2. 용어

- **회차**: 이번 사용이 몇 회째인지 = (기존 누적 사용 횟수) + 1. 보상 단계는 회차로 정한다. 사용 후 누적 사용 횟수 +1.
- **누적 사용 횟수(uses)**: 게임 전체 누적. 회복으로 줄지 않는다. 회복 행동 자신도 사용 횟수는 증가한다(단계가 없어 영향 없음).
- **습관(habits)**: 밤 추첨 확률에만 쓴다. 일반 행동(즉시·안정·성장)을 **낮에** 실행하면 +1. 밤 실행·회복 행동은 습관을 만들지 않는다. 0 미만 불가.
- **하루 사용 횟수(dailyUses)**: 낮+밤 합산, 다음 낮 시작 시 0.
- **연속 사용(streak)**: 같은 날 직전 *실제 행동*이 같은 행동이면 연속. 낮 슬롯 3 → 밤 1회차로 이어진다. 무행동(소비된 칸 포함)·회복 행동이 끊고, 다음 낮 시작 시 초기화.
- **낮 전용 부가효과**: 산책·회복의 습관 감소, 친구 보너스, 봉사 보너스. 밤에는 발생하지 않는다. 음악의 밤 보너스는 밤 전용이다.
- 쇼핑 재사용 감점, 게임 몰아하기 연속 감점, 요리 첫 사용 보너스, 공부 하루 1회 고단계 제한은 **보상 조건**이므로 낮·밤 모두 적용한다(하루 기준은 낮+밤 합산).

## 3. 행동 규칙표

### 즉시 (습관 형성)

| 행동 | 회차별 점수 | 추가 조건 |
|---|---|---|
| 음주 | 1~2회 **+8** / 3~4회 **+3** / 5~6회 **-4** / 7회~ **-8** | — |
| 흡연 | 1~2회 **+4** / 3~5회 **+1** / 6회~ **-2** | — |
| 도박 | 1~2회 승률 55% **+9** / 패 **-3** (기대 +3.6)<br>3~5회 승률 40% **+7** / 패 **-5** (기대 -0.2)<br>6회~ 승률 25% **+6** / 패 **-7** (기대 -3.75) | 승패 난수는 밤 추첨과 별도로 한 번 더 뽑는다 |
| SNS | 1회 **+5** / 2~3회 **+2** / 4~5회 **0** / 6회~ **-3** | — |
| 쇼핑 | 1~2회 **+7** / 3~4회 **+2** / 5회~ **-5** | 같은 날(낮+밤) 이미 쇼핑했으면 추가 **-3** |
| 게임 몰아하기 | 1~2회 **+7** / 3~4회 **+2** / 5회~ **-5** | 직전 실제 행동도 게임 몰아하기(연속)면 추가 **-3** |

### 안정 (습관 형성)

| 행동 | 점수 | 추가 조건 |
|---|---|---|
| 산책 | **+2** | 낮: 지정 대상 습관 **-1** (자기 습관 +1을 먼저 적용하므로 산책 자신을 대상으로 하면 순변화 0) |
| 음악 감상 | **+3** | 밤 추첨으로 실행되면 추가 **+2** (밤 합계 +5) |
| 요리 | **+3** | 그날(낮+밤) 첫 요리면 추가 **+2** |
| 친구 만나기 | **+3** | 낮: 같은 슬롯 번호에서 비기권자 2명 이상이 친구 만나기를 고르면 각자 추가 **+3** |
| 봉사 활동 | **+3** | 낮: 그 슬롯 처리 직전 비기권자 전체 중 최저 점수(동점 포함)면 추가 **+3** |

### 성장 (습관 형성)

| 행동 | 점수 | 추가 조건 |
|---|---|---|
| 공부 | 1~2회 **+1** / 3~4회 **+3** / 5~7회 **+7** / 8회~ **+10** | +7·+10(고단계) 보상은 하루(낮+밤) **1회**. 같은 날 그 이후 고단계 회차는 기본 **+1** (회차는 계속 증가) |
| 운동 | 1~3회 **+1** / 4~6회 **+2** / 7~10회 **+3** / 11~15회 **+4** / 16회~ **+5** | 일일 제한 없음 |
| 업무·프로젝트 | 매회 **+1** | 회차가 3의 배수(3, 6, 9…)면 완료 보너스 **+7** |
| 창작 활동 | 매회 **+1** | 완성 보너스 **+10**, 확률 = 회차 × 5% (최대 40%, 8회째부터 40%) |
| 관계·연애 | 1단계(1~2회) **+1** / 2단계(3~5회) **+2** / 3단계(6~9회) **+3** / 4단계(10회~) **+4** | 단계에 처음 들어서는 회차에 도달 보너스: 3회째 **+3**, 6회째 **+5**, 10회째 **+8**. 개인 진행, 다른 사람 입력 불필요 |

### 회복 (습관 형성 안 함 → 밤에 뽑히지 않음)

| 행동 | 행동력 | 점수 | 효과 (낮에만) |
|---|---|---|---|
| 휴식 | 1 | 0 | 지정 대상 습관 **-3** |
| 명상 | 1 | **+1** | 지정 대상 습관 **-1** |
| 디지털 디톡스 | 1 | 0 | SNS·게임 몰아하기 습관 각 **-2** (대상 지정 없음) |
| 환경 바꾸기 | **2** | 0 | 지정 대상 습관을 **0**으로 |

- 대상은 일반 행동(즉시·안정·성장 15개) 중 하나. 자기 습관을 대상으로 해도 된다. 산책·휴식·명상·환경 바꾸기는 대상 필수, 그 외는 대상 지정 불가.
- 환경 바꾸기는 `slots[i]`(i = 0 또는 1)에 두고 `slots[i+1]`은 반드시 빈 칸(null). 효과는 i번째 슬롯 처리 때 적용, i+1번째는 "진행 중"(무행동 취급, 연속 끊김).

## 4. 정산 순서

**낮 시작:** 비기권자의 하루 사용 횟수·연속 사용·하루 단위 기록(공부 고단계 사용 여부) 초기화. 미제출·잘못된 계획은 무행동 3칸.

**낮 슬롯:** 슬롯 0 → 1 → 2. 각 슬롯마다
1. 처리 직전 상태로 공동 효과 판정: 최저 점수(동점 포함) 참가자 목록, 친구 만나기 선택 인원.
2. 모든 참가자의 해당 슬롯을 처리(서로의 상태에 영향 없음 → 처리 순서와 무관).

**행동 1개 처리:** ① 회차 보상·조건부 보너스/감점 합산 ② 점수에 더하고 0 미만이면 0 ③ 누적·하루 사용 횟수 +1 ④ 연속 사용 갱신 ⑤ (낮만) 일반 행동이면 자기 습관 +1 ⑥ (낮만) 대상 습관 감소(0 하한).

**밤:** 낮 효과를 모두 적용한 습관으로 분포 확정. 행동 A 확률 = A 습관 / 습관 합계. 2회 복원 추출(합계 0이면 2회 모두 무행동). 뽑힌 행동은 회차 보상·확률·음악 밤 보너스·보상 조건만 적용하고 사용 횟수를 올린다. 습관은 바뀌지 않는다.

**난수 순서(재현용):** 참가자는 playerId 문자열 오름차순으로 처리한다(입력 배열 순서와 무관). 낮에는 슬롯 순서대로 도박·창작이 난수를 1개씩 쓰고, 밤에는 참가자별로 [추첨, (도박·창작이면) 내부 난수, 추첨, (내부 난수)] 순서로 쓴다. 추첨은 `rng × 습관합계`를 행동 목록 순서(음주, 흡연, 도박, SNS, 쇼핑, 게임, 산책, 음악, 요리, 친구, 봉사, 공부, 운동, 프로젝트, 창작, 관계)로 누적해 고른다.

**승리 판정(밤 이후):** 비기권자 0명 → 승자 없이 종료 / 1명 → 그 사람 승리 / 최고 점수 ≥ 100 → 최고 점수자 전원(공동) 승리 / 그 외 10일째면 최고 점수자 전원 승리 / 아니면 다음 낮.

## 5. 예시 한 턴 (2인, 3일째)

**시작 상태 (2일째 밤 종료 후)**

| | 점수 | 누적 사용 | 습관 |
|---|---|---|---|
| A | 30 | 음주 3, 음악 2, 공부 4 | 음주 3, 음악 2, 공부 2 |
| B | 24 | 쇼핑 2, 친구 1 | 쇼핑 2, 친구 1 |

**계획** — A: [공부, 친구 만나기, 휴식→음주] / B: [봉사 활동, 친구 만나기, 쇼핑]

**낮 슬롯 0** (직전 점수 A 30, B 24 → 최저 B)
- A 공부: 5회째 = 고단계 +7 (오늘 첫 고단계) → **37**, 공부 습관 3
- B 봉사: 기본 +3, 최저 점수 보너스 +3 = +6 → **30**, 봉사 습관 1

**낮 슬롯 1** (친구 만나기 선택 2명)
- A 친구: +3 + 친구 보너스 +3 → **43**, 친구 습관 1
- B 친구: +3 + 3 → **36**, 친구 습관 2

**낮 슬롯 2**
- A 휴식(대상 음주): 점수 0 → **43**, 음주 습관 3 → 0 (공부·휴식의 누적 사용은 유지, 휴식 사용 1)
- B 쇼핑: 3회째 +2 (오늘 첫 쇼핑이라 감점 없음) → **38**, 쇼핑 습관 3

**밤 분포**
- A: 음악 2, 친구 1, 공부 3 (합 6) → 음악 33%, 친구 17%, 공부 50%. 누적 구간: 음악 [0,2), 친구 [2,3), 공부 [3,6)
- B: 쇼핑 3, 친구 2, 봉사 1 (합 6) → 쇼핑 50%, 친구 33%, 봉사 17%. 누적 구간: 쇼핑 [0,3), 친구 [3,5), 봉사 [5,6)

**밤 추첨** (난수 0.6, 0.2, 0.1, 0.7 순서. A가 먼저)
- A 1회: 0.6×6 = 3.6 → 공부, 6회째는 고단계지만 오늘 이미 받음 → 기본 +1 → **44**
- A 2회: 0.2×6 = 1.2 → 음악, 기본 +3 + 밤 보너스 +2 = +5 → **49**
- B 1회: 0.1×6 = 0.6 → 쇼핑, 4회째 +2, 같은 날 재사용 -3 = -1 → **37**
- B 2회: 0.7×6 = 4.2 → 친구, 기본 +3 (밤에는 친구 보너스 없음) → **40**

**결과:** A 49, B 40. 둘 다 100 미만이고 3일째 < 10 → 4일째 낮으로. 밤에 습관은 변하지 않았다(A: 음주 0·음악 2·친구 1·공부 3). 이 예시는 실제 `resolveDay`로 같은 결과가 나오는 것을 확인했다.

## 6. 초기 밸런스 근거

- 2인 게임에서 한 사람이 같은 전략을 반복한 400시드 간이 시뮬레이션 결과(목표 도달 일차 평균): 음악 반복 6.0일, 안정 혼합(음악·요리·봉사) 6.0일, 운동 반복 6.0일, 공부+운동 6.1일, 프로젝트 반복 6.0일, 성장 혼합 6.1일, 초반 즉시 보상 후 회복·성장 전환 7.2~7.4일.
- 즉시 보상 순환(6개 즉시 행동만 돌려 쓰기): 10일 안에 100 도달 3%, 평균 최종 점수 4점. 즉시 행동 6개의 양수 보상을 전부 합쳐도 도박 운을 빼면 약 78점이라 손실 단계 전에 100에 닿을 수 없다.
- 안정·성장은 위험 없이 평균 6일 전후에 도달. 공부는 하루 1회 고단계 제한으로 집중 투자보다 하루 1회 섞어 쓰는 편이 효율적이다.
- 남은 과제(6단계): 공동 효과(친구·봉사)의 인원별 가치, 즉시→성장 전환 전략의 보상, 밤 역전 빈도 측정 후 조정.
