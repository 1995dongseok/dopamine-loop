# 밸런스 시뮬레이션 보고서 (6단계)

규칙 버전 1.0.0 · 최종 수치 해시 `a25a5edeffc4ddf9` (조정 전 `cad305039fc48064`)

PLAN.md 10장의 밸런스 검증 계획에 따라, 실제 규칙 함수(`resolveDay`, `checkWinner`, `validatePlan`, `createPlayerState`, `seededRng`)만으로 봇끼리 대전시켜 수치를 조정했다. 수치의 단일 출처는 `src/shared/rules/actionData.ts`이고, 조정 후 표는 `docs/RULES.md`에 있다.

## 1. 방법

- **엔진**: `sim/engine.ts`의 `playGame`이 매일 각 봇에게 계획을 받아 `validatePlan`으로 검사(무효면 예외)한 뒤 `resolveDay` → `checkWinner`를 반복한다. 점수·밤 추첨·승리 판정을 시뮬레이터가 따로 계산하지 않는다.
- **봇의 판단**: 봇은 `sim/model.ts`에서 `ACTION_DATA`를 읽어 "다음 사용의 기대 점수"와 "밤 1회 기대 점수"를 추정해 고른다. 추정은 계획용일 뿐이고 실제 결과는 항상 규칙 함수가 낸다.
- **실행 구성** (`npm run sim`, 기본 시드 1,000개):
  1. **속도**: 같은 전략 2명이 목표 도달 후에도 10일째까지 진행. 목표 도달 일차와 10일째 점수.
  2. **2인 1:1 대전표**: 서로 다른 전략 쌍마다 1,000판. 홀수 시드는 좌석을 바꾼다(playerId 순서가 규칙의 난수 사용 순서라서 좌석이 결과에 영향을 준다). 승 1점, 공동 승 0.5점.
  3. **무작위 구성 풀**: 2·4·6인 각 1,000판. 좌석마다 6개 전략 중 하나를 시드 고정 난수로 뽑으므로 구성과 좌석 순서가 모두 바뀐다(같은 전략 여러 명 가능).
- **재현성**: 게임 시드 `mixSeed(n, i)`, 좌석 배정 `seededRng(mixSeed(gameSeed, 99))`, 1:1 `mixSeed(2000, a, b, i)`, 속도 `mixSeed(3000, s, i)`, 봇 난수 `mixSeed(gameSeed, 7919, seat)`. 결과 JSON에 규칙 버전, 수치 해시(ACTION_DATA + GAME_CONSTANTS의 SHA-256 앞 16자리), 전략 설명, 시드 방식을 함께 저장한다. 같은 수치와 옵션이면 출력 JSON이 바이트 단위로 같다(확인함).
- **기록 지표**: 전략별 승률(공동 승리를 각자 승으로 셈)·단독 승 수, 공동 승리율, 종료 일차 분포·평균, 행동·유형별 선택률(낮 계획 기준), 회복 빈도(회복 행동 슬롯 비율, 회복을 쓴 참가자-일 비율), 밤 역전(밤 직전 단독 선두가 밤 이후 선두가 아니게 된 횟수, 마지막 밤 역전으로 승자가 바뀐 판), 손실 후 회복(최고점 대비 8점 이상 떨어진 적이 있는 참가자의 승리·목표 도달 비율), 첫 손실 전 승리 비율.

## 2. 전략 (`sim/strategies.ts`)

| ID | 이름 | 내용 |
|---|---|---|
| stable | 안정형 반복 | 매일 [요리(최저 점수면 봉사), 친구 만나기, 음악 감상] |
| growth | 성장형 집중 | 매일 [공부, 관계·연애, 관계·연애] (하루 1회 제한이 있는 공부 + 한 성장 행동에 집중) |
| instant | 즉시 보상 순환 | 슬롯마다 즉시 행동 6개 중 다음 회차 기대 점수 최대. 회복 없음 |
| early_instant | 초반 즉시 후 성장 전환 | 1~2일째 공부 1칸 + 남은 칸은 기대 점수 ≥5인 즉시 행동. 3일째부터 밤에 손해인 습관을 하루 1칸 회복(명상/휴식/디톡스/환경 바꾸기)하며 [공부, 프로젝트, 관계] |
| mixed | 위험 증가 시 회복 혼합 | 기대 ≥5인 즉시 행동은 하루 1개까지. 밤에 손해인 습관 비중이 30% 이상이면 회복 1칸. 나머지는 [공부, 요리(최저면 봉사), 음악] |
| greedy | 기대값 탐욕형 | 슬롯마다 (낮 기대 점수 + 습관 변화로 인한 밤 기대 점수 변화 × 남은 일수 가중)을 최대화. 회복·산책 포함 |

친구 만나기는 모든 봇이 가운데 칸(슬롯 1)에만 둔다(말로 맞추는 플레이를 흉내 낸 관례).

### 4.5 행동 선택률 (낮 계획 기준, 조정 후 2인 / 4인 / 6인)

- 유형: 즉시 30.0 / 28.5 / 27.4%, 안정 31.6 / 33.3 / 34.4%, 성장 34.4 / 33.9 / 33.6%, 회복 4.0 / 4.4 / 4.7% (조정 전 회복 1.4 / 1.5 / 1.6%).
- 많이 쓰인 행동: 공부 약 17.5%, 관계·연애 약 13%, 음악 약 12%, 요리 8~11%, 흡연 7~11%, 친구 만나기 약 7%.
- 쓰이지 않은 행동: 운동·창작 0%, 휴식·디지털 디톡스·환경 바꾸기 0%(회복은 거의 명상), 산책 0.4~0.5%. 봇이 쓰는 대상이 좁아서 생긴 결과이고, 이 행동들이 쓸모없다는 뜻은 아니다. 즉시 습관이 대부분 1씩만 쌓여서 휴식(-3)이나 환경 바꾸기까지 갈 일이 거의 없다.

### 4.6 밤 역전과 손실 후 회복

- 밤 역전이 한 번이라도 있었던 판: 2인 50% / 4인 65% / 6인 67%(조정 전 43 / 58 / 65%). 마지막 밤 역전으로 승자가 바뀐 판: 5.1 / 7.6 / 8.9%.
- 최고점 대비 8점 이상 떨어진 적이 있는 참가자: 대부분 즉시 보상 순환 봇이다. 이 봇을 빼면 2인 23명 중 승리 21.7%, 목표 도달 43.5%, 4인 54명 중 도달 13.0%(승리 0%), 6인 72명 중 도달 4.2%(승리 0%). 2인에서는 손실 후에도 따라잡을 수 있지만, 4·6인에서는 큰 손실이 사실상 탈락이다. 봉사 보너스를 +5로 올려도 부족했다.

## 5. 한계와 남은 문제

- **봇 결과는 균형의 증명이 아니다.** 전략 6개는 단순한 규칙 기반 봇이고, 사람은 상대를 보고 친구 만나기를 맞추거나, 선두를 견제하거나, 습관을 계산해서 고른다. 실제 그룹 플레이(최소 3회)로 선택 이유·대기 시간·밤의 긴장감·재플레이 의향을 확인해야 한다(PLAN 10장). 실제 플레이 시간도 따로 재야 한다.
- **초반 즉시 후 성장 전환은 경쟁력이 부족하다.** 이 규칙에서 즉시 행동의 가치는 사용 횟수로만 정해지고 시점과는 무관하다. 그래서 초반에 몰아 쓰면 습관이 더 오래 남고 성장 투자만 늦어진다. 같은 맛보기를 하루 1개씩 나눠 쓰는 혼합형이 구조적으로 항상 유리하다. 즉시 첫 보상을 키우면 전환형도 좋아지지만 혼합형·탐욕형이 더 강해져서(시험값: 혼합형이 안정형·성장형을 80~85%로 이김) 채택하지 않았다. 수치만으로는 풀기 어렵고, 고치려면 "초반 며칠 즉시 보상 보너스" 같은 규칙 변경이 필요하다(규칙 담당 판단 필요).
- **맛보기 후 회복이 최적이다.** 혼합형·탐욕형이 여전히 가장 강하다(1:1에서 안정·성장·전환형을 53~88%로 이김). 즉시 행동 1회째(+7)를 쓰고 명상으로 습관을 지우는 흐름이 안정 행동 두 칸보다 조금 이득이다. 주제("도파민을 맛보되 관리")와는 맞지만, 사람들이 이 패턴만 쓰는지 플레이 테스트로 봐야 한다.
- **인원에 따라 강한 전략이 다르다.** 성장형은 2인(긴 판)에서 강하고 6인(빨리 끝나는 판)에서 약하다(12%). 안정형은 반대다. 목표 점수를 인원별로 바꾸는 것은 규칙 변경이라 하지 않았다.
- **한 행동만 반복하는 전략이 강하다(탐색 중 관찰, `npm run sim`에는 포함 안 함).** 한 습관만 쌓으면 밤 2회도 모두 그 행동이 나와서 하루 사용이 5회가 된다. 조정 후에도 관계·연애만 3칸 반복하면 안정형을 약 90%로 이겼다(탐욕형 상대로는 약 32%). 공부만 하루 1회 제한이 있어서 이 효과가 없다. 운동·관계에 일일 제한이나 체감 같은 규칙을 넣을지 플레이 테스트 후 판단하는 것이 좋다.
- 6인 평균 종료 5.66일은 목표 범위(5~8일) 하한에 가깝다.
- 분산이 작다. 결정적인 행동이 많아서, 평균 몇 점 차이만 나도 1:1 승률이 80~100%로 벌어진다. 대전표의 큰 숫자는 큰 실력 차이가 아니라 작은 기대값 차이일 수 있다.

## 6. 재현 방법

```bash
npm run sim                                   # 1,000시드, 표 출력 + sim/results/summary.json 저장
npm run sim -- --seeds 2000 --out /tmp/x.json # 시드 수·출력 경로 변경
npx vitest run sim                            # 결정성 테스트 (sim/sim.test.ts)
```

- `sim/results/summary.json`: 조정 후 결과(커밋 대상, 약 13KB). `sim/results/baseline-summary.json`: 같은 봇으로 조정 전 수치를 돌린 결과(수치 해시 `cad305039fc48064`). 원래 수치로 다시 만들려면 `actionData.ts`를 3장의 "이전" 값으로 되돌리고 `npm run sim -- --out sim/results/baseline-summary.json`을 실행한다.
- 1,000시드 전체 실행은 약 25초 걸린다(대전표 30쌍 × 1,000판 + 풀 3,000판 + 속도 6,000판).
- 수치나 봇을 바꾸면 수치 해시나 결과가 달라진다. 이 문서와 `docs/RULES.md`의 표·예시도 함께 갱신한다.
